Consider a 2D "ribbon" lattice of infinite length and finite width. Model electronic properties of the ribbon using the tight-binding approach with one orbital per lattice site. Overlap matrix is approximately $\mathbb{I}$, and hopping parameters are provided.

Construct the tight-binding $H(k)$, where $k=k_x$ the wave vector along the long axis of the ribbon. $H(k)$ should be an $M\times M$ matrix, where $M$ is the number of sites within one cell of the translationally symmetric long axis of the ribbon.

NOTE: $x$-axis is not necessarily along a particular lattice axis.

## Assignment:
1. Plot energy spectrum $E_n(k)$ within first BZ for two values of the ribbon width $W_1$, $W_2=2W_1$. Does the system exhibit an even-odd effect?
2. Plot trasverse profiles $|\psi_{nk}(i)|^2$ as functions of the vertical positions $y_i$ within one cell for representative states $\ket{nk}$.
3. Play with the model, modify tight-binding parameters to explore different regimes. Report interesting or unexpected features.

### Features of the Model:
* Lattice is generated by lattice primitives $\vec{a}_1=a_{1x}\hat{x}+a_{1y}\hat{y}$ and $\vec{a}_2=a_{2x}\hat{x}+a_{2y}\hat{y}$.
* If the crystal has a two-atom basis, the corresponding vectors are $\vec{\tau}_1=\vec{0}$ and $\vec{\tau}_2=d_x\hat{x}+d_y\hat{y}$.
* If two-atom basis, on-sight energies $\epsilon_1$ and $\epsilon_2$ respectively. Or else use $\epsilon_0=0$.
* Use NN Hopping $t_{nn}=-t$, NNN hopping only if specified. $t$ is unspecified and serves as unit energy.

### Specifics of assignment for Team 3 (Baishali and Hunter):
* Hexagonal Lattice, no basis.
  - $\vec{a}_1=\frac{\sqrt{3}}{2}a\hat{x}-\frac{1}{2}a\hat{y}$
  - $\vec{a}_2=\frac{\sqrt{3}}{2}a\hat{x}+\frac{1}{2}a\hat{y}$
* only NN hopping.
